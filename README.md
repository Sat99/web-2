# Klub Ada Website

This is the official website for Klub Ada, a community for women in technology in Slovenia. The website is built with HTML, CSS, and JavaScript.

## Features

- Responsive design
- Mobile-friendly navigation
- Modern UI/UX
- Cross-browser compatible

## Structure

```
.
├── index.html              # Home page
├── o-nas.html             # About page
├── blog.html             # Blog page
├── dogodki.html         # Events page
├── partnerstvo.html    # Partnership page
├── public/
│   ├── css/            # Stylesheets
│   ├── js/            # JavaScript files
│   ├── assets/       # Images and other assets
│   └── favicon.ico  # Favicon
└── README.md        # This file
```

## Development

To run this website locally:

1. Clone the repository
2. Open `index.html` in your browser
